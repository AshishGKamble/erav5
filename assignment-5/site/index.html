A recipe is a hypothesis until a cheap run tests it

Compare candidate design sets, then expand the winner.

Each set is a full mixture recipe we decide; each is scored by a tiny proxy on the same 5 lanes. Compare them, add tuning sets, pick one - then expand it to the shipped 7-lane staged plan below. This is the loop the plan commits to at 1B/3B scale.

01

The candidate sets, side by side

Three recipes we decided. Recipe = the run-integrated budget split (the whole-run average, seed through anneal - not any single stage); outcome = per-lane held-out loss from the proxy trained on that flat mixture (lower is better). The proxy tests 5 lanes; agentic + long-context need real scale, so they enter only in the expanded plan (§2), and the stage-by-stage schedule of the chosen set is in §3.
