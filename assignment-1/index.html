S1-1

Activations exist for a reason.

A model with no nonlinearity can only draw a straight boundary, so it cannot separate two interleaved rings. Adding one ReLU hidden layer can.

epoch 0 Only the activation changed. The boundary picture is the proof.
S1-2

Depth without nonlinearity is a lie.

Five stacked linear layers collapse to a single linear map, so a 5-layer linear net is no stronger than 1 layer. Both fail the ring task identically. Inserting ReLUs between the same five layers solves it.

S1-3

Embeddings learn similarity from nothing but next-token.

Trained only to predict the next token in a tiny synthetic grammar, the embedding table clusters related tokens, though similarity was never supplied. Same-category tokens share next-token distributions, so they end up neighbors.

The grammar

animals: cat, dog, cow
fruits: apple, mango
verbs: eat, chase, see

Nearest neighbor is same category

-

For each token, its closest neighbor in embedding space belongs to the same category. That structure was never labeled. It emerged from next-token prediction alone.

S1-4

Memorization vs generalization, and data closes the gap.

A high-capacity net on tiny data drives train accuracy to nearly 100% while held-out accuracy stays low. It memorizes. Growing the dataset closes the gap. The same over-parameterized network is trained at three dataset sizes.

Blue is training accuracy, orange is held-out accuracy. Data is everything.

Four claims, four tiny networks, one point: what a model can represent is decided by nonlinearity, depth used honestly, the signal in its data, and how much of that data it sees.
