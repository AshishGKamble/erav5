S1-1

Activations exist for a reason.

A straight line can never trap a ring inside a ring. One ReLU bend can.

A model with no nonlinearity can only draw a straight boundary, so it cannot separate two interleaved rings. Adding one ReLU hidden layer can.

300 noisy points · two concentric rings Inner ring = class 0 · outer ring = class 1 · the two are not linearly separable
How to read this
  • Each dot is a data point. Its position is its two inputs; its color is its true class (red = 0, blue = 1).
  • The shaded background is what the model predicts everywhere. The seam where red meets blue is its decision boundary.
  • Good means each dot sits on background of its own color. The badge is accuracy on all 300 points.
Why it is true
  1. Identity preserves linearity. W₂(W₁x + b₁) + b₂ algebraically collapses to a single Ax + c, so the best it can draw is one straight line.
  2. ReLU creates bends. Each hidden unit adds a hinge; together the hinges approximate a closed curve around the inner ring.
  3. The boundary is the evidence. One stays a line near 50%. The other wraps the ring near 100%. Only the activation changed.
Re-initializes weights and trains again. New dataset resamples the rings.
S1-2

Depth without nonlinearity is a lie.

Five stacked linear layers hold no more power than one. ReLU between the same layers changes everything.

Five stacked linear layers collapse to a single linear map, so a 5-layer linear net is no stronger than 1 layer. Both fail the ring task identically. Inserting ReLUs between the same five layers solves it.

That single matrix is exactly what one linear layer already is.

How to read this
  • Same rings, same reading as S1-1: dots are points, background is the model's prediction, the seam is the boundary.
  • Compare the first two panels. If depth mattered, the middle one would look different. It does not.
  • The loss curve overlays all three so you can watch the two linear nets stay locked together.
Why it is true
  1. Linear composed with linear is linear. A stack of matrices multiplies into a single matrix, shown live in the box above.
  2. So capacity does not grow with depth until you add a nonlinearity between the layers.
  3. ReLU is that nonlinearity. The same five layers, now with bends, wrap the ring the linear stack never could.
The 1-layer and 5-linear-layer boundaries stay the same line every run.
S1-3

Embeddings learn similarity from nothing but next-token.

No one labeled which words are alike. The model was only asked to predict what comes next.

Trained only to predict the next token in a tiny synthetic grammar, the embedding table clusters related tokens, though similarity was never supplied. Same-category tokens share next-token distributions, so they end up neighbors.

The grammar

animals: cat, dog, cow
fruits: apple, mango
verbs: eat, chase, see

Sentences follow simple rules (animal → verb → fruit or animal). Every animal is followed by the same kind of word, so all animals share a next-token distribution. Same for fruits and verbs.

How to read this
  • This is not a decision boundary. Each dot is a word, labeled next to it.
  • Each word owns a 16-number vector; we squash it to 2D with PCA just to plot it. Distance = similarity.
  • Color is category, which the model never saw. Watch same-category words drift into the same clump.
Why it is true
  1. Shared context, shared gradient. Words that predict the same next-words receive the same training signal.
  2. So their vectors are pushed together even though nothing said "cat is like dog".
  3. The count is the proof. Every token's nearest neighbor ends up in its own category. Similarity emerged from prediction alone.

S1-4

Memorization vs generalization, and data closes the gap.

One over-parameterized network. Three dataset sizes. Watch the gap between train and test collapse.

A high-capacity net on tiny data drives train accuracy to nearly 100% while held-out accuracy stays low. It memorizes. Growing the dataset closes the gap. The same network is trained at three dataset sizes.

How to read this
  • All three panels are the same network, trained on 20, 200, then 2000 points.
  • Two badges per panel: blue is accuracy on the training points, orange is accuracy on unseen test points.
  • In the chart, the vertical dashed span between the lines is the generalization gap at each size.
Why it is true
  1. Capacity outruns tiny data. With 20 points a big net just memorizes them, including the 10% flipped labels.
  2. Memorizing is not learning. On new points that memory does not transfer, so test accuracy lags far behind train.
  3. Data constrains the model. More points leave fewer ways to fit them, so the net finds the real boundary and the gap closes.
Data is everything: same model, more data, smaller gap.
